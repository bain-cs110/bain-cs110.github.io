Tuples: The Rules

  1. The items in a tuple can be of any type
  2. A tuple can be of any length
  3. You can access any tuple element through 0-based indexing
  4. You can slice tuples
  5. You cannot edit tuples (immutability)
  6. You can concatenate tuples to create new, longer tuples

Lists: The Rules

  1. The items in a list can be of any type
  2. A list can be of any length
  3. You can access any list element through 0-based indexing
  4. You can slice a list
  5. You can edit a list (mutable)
  6. You can concatenate lists using the + operator
  7. You can sort lists (as long as Python knows how to sort your data)
  8. You can add elements to a list using the append function
  9. You can remove elements in a list using the pop function
  10. You can update specific elements in a list using the offset notation from #3.

Scope

  1. Scope — refers to the part of the program where a variable is accessible
  2. Global variable — a variable which is defined in the main body of a file (best avoided)
  3. Local variable — a variable which is defined inside a function. Not accessible from outside the function
    1. The parameter names in the function definition behave like local variables, but they contain the values that we pass into the function when we call it.
